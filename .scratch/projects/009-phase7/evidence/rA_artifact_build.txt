[2] artifact: tree-sitter CLI 0.25.3 `build --wasm` over the REAL rust grammar
    source (tests/fixtures/rust):
      $ tree-sitter generate src/grammar.json
      $ tree-sitter build --wasm -o rust.wasm .
      -> rust.wasm  1114265 bytes (1.1 MB)
    module ABI: standalone SIDE_MODULE — imports ONLY libc (calloc, free,
    iswspace, iswalpha) + memory + dylink globals/table; exports only
    tree_sitter_rust + ctors. The full parse tables + lex fns live in the
    module; the host parse engine is the tree-sitter C library (wasm_store.c).

[3] runtime: wasmtime 29.0.0 (the exact version tree-sitter 0.25.3 pins in
    Cargo.lock), Python wheel _libwasmtime.so (16 MB); libtree-sitter compiled
    with TREE_SITTER_FEATURE_WASM against wasmtime's C API headers (v29.0.0
    tag), gcc 14.2.1, -O2. Bridge: ctypes over ts_wasm_store_* + ts_parser_*
    (probe_wasm_runtime.py). Real parse of the rust grammar: abi=15, correct
    sexp (function_item/let_declaration/macro_invocation/if_expression...),
    has_error=False.
